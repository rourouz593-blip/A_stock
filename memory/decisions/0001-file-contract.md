# ADR-0001：Agent 之间用文件契约通信

- 日期：2026-01-02
- 状态：已采纳

## 背景

多个 agent 需要协作完成一次分析。通信方式有三种候选：
共享内存对象、函数直接调用、文件交换。

## 决定

采用**文件交换**：每个 agent 读固定路径的输入文件、写固定路径的输出文件，
结构由 `schemas/` 下的 JSON Schema 约束。

## 理由

1. **可观察** — 出错时能直接打开中间产物看是哪一步坏的
2. **可复现** — run 目录拷走即可复现，不依赖进程状态
3. **可断点续跑** — 单步失败只需重跑该步
4. **harness 无关** — 换 Claude Code / opencode / 纯脚本都能跑，不绑定任何 SDK
5. **教学友好** — 学生能"看见"agent 之间在传什么

## 代价

- 比内存传参慢（对分析类任务可忽略）
- 需要额外维护 schema 与校验步骤（用 `tools/validate_artifact.py` 抵消）
