# 全项目口径约定

> 这些约定一旦确定就**不要在单个 agent 里私自变通**。变通必须改这里，并同步改 schema。

| 项目 | 约定 | 状态 |
|---|---|---|
| 股票代码 | 六位数字 + `.SH` / `.SZ` / `.BJ` | ✅ 已定 |
| 日期 | `YYYY-MM-DD`；时间戳用 ISO8601 带时区 | ✅ 已定 |
| 金额单位 | 一律「元」(CNY_yuan)，在 Provenance.unit 声明 | ✅ 已定 |
| 财务对齐 | 按**披露日**（ann_date），非报告期 | ✅ 已定 |
| 报表口径 | 默认合并报表 | ✅ 已定 |
| 复权口径 | TODO(strategy)：前复权还是后复权？一个 dataset 内必须唯一 | ⬜ 待定 |
| 行业分类 | TODO(strategy)：申万 / 中证 / 证监会？影响同业对比结论 | ⬜ 待定 |
| 交易日历 | TODO(datasource)：以哪个源为准 | ⬜ 待定 |
