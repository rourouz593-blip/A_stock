# 风险与纪律

## 0. 立场

**仓位管理决定你能在市场里待多久，选股只决定你待着的时候赚多少。**
所以这一章的所有数字都由代码算（`tools/compute_risk.py`），不许模型心算——
心算错一个小数点，风险判断就完全反了。

## 1. 计算顺序

```
① 账户总资产 equity        ← .env 的 ASTOCK_ACCOUNT_EQUITY
② 总市值 = Σ(收盘价 × 数量)
③ 总仓位% = 总市值 / equity
④ 单票权重% = 单票市值 / equity
⑤ 同题材权重% = Σ(同 sector 的市值) / equity      ← 最容易被忽略的一项
⑥ 单笔风险 = (收盘价 − 失效位) × 数量
⑦ 单笔风险占比% = 单笔风险 / equity
⑧ 是否超 0.5%
⑨ 当日最大允许亏损 = equity × 日内止损比例
⑩ 是否应停止新增交易
```

## 3. 同题材风险：最常见的隐形杠杆

三只票分别占 8%、7%、6%，看起来分散。
但如果它们都属于同一个题材，实际上就是**一个 21% 的仓位**——
题材退潮时它们会同时下跌，分散是假的。

所以 `concentration` 必须按 `sector` 聚合后再判断，不能只看单票。

## 4. "是否停止新增交易"的判定

满足任意一条即停：

1. 当日亏损已触及最大允许亏损
2. 总仓位已达明日上限
3. 情绪阶段为 `退潮`（来自 `market.json`）
4. 七条行为自检中触发了 3 条及以上

     行为失控比亏钱更危险。 -->

## 5. 缺 equity 怎么办

没有 `ASTOCK_ACCOUNT_EQUITY` → **风险金额一律留空并说明**。

绝不许拿持仓总市值当账户总资产估算：
满仓的人和三成仓的人，同样的持仓市值对应的风险完全不同。

## 6. 输出要求

`positions_review.json` 的 `risk` 段每个数字都要能追溯到上面的公式。
`stop_trading.reason` 必须写清是哪一条触发的。
