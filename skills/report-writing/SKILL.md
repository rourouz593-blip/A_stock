# 报告写作规范

## 1. 结构

见 `templates/report_template.md`（固定章节，不得增删主章节）。

## 2. 语言规范

- 结论先行，每节第一句就是这一节的判断。
- 每条判断后标注来源 agent，例如 `[fundamental]`。
- 数字必须带口径与时间，例如"2025Q3 扣非净利同比 +12.4%"而不是"利润增长不错"。
- 不确定就写不确定，禁止用"大概率""明显""显然"掩盖证据不足。
- 禁止出现买卖指令、目标价、仓位建议。
