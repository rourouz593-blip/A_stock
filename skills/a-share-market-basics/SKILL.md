> 作用：**防止把美股/港股的分析习惯套到 A 股上**，也防止把常识性口径搞错。

## 2. 交易制度要点

- **T+1**：当日买入不能当日卖出。这决定了"打板"的风险是隔夜风险。
- **涨跌停板**：会**截断**技术指标信号。一字板当天几乎无成交，
  用它算出的动量、量比都失真。
- **集合竞价**：9:15—9:25，9:20 前可撤单。竞价表现是次日预案的第一个观察点。
- **停复牌**：停牌日不产生行情。数据层按交易日历跳过，不补值。

## 3. 短线术语对照

| 术语 | 含义 |
|---|---|
| 连板 | 连续涨停的天数，如"3板"= 连续 3 个涨停 |
| 炸板 | 盘中触及涨停后打开且收盘未封住 |
| 晋级 | 昨日涨停股今日继续涨停 |
| 打板 | 在涨停价买入 |
| 低吸 | 在回调时买入 |
| 龙头 | 一个题材里定方向的那只 |
| 中军 | 题材里市值最大、机构认可度最高的 |
| 一日游 | 涨停次日即大幅回落 |

## 4. 披露节奏

| 报告 | 披露窗口 |
|---|---|
| 年报 | 次年 1—4 月 |
| 一季报 | 4 月 |
| 半年报 | 7—8 月 |
| 三季报 | 10 月 |
| 业绩预告 | 强制条件见交易所规则 |

**报告期 ≠ 披露日。** 分析里一律按披露日对齐，否则产生前视偏差。

## 6. 数据口径陷阱

| 陷阱 | 说明 |
|---|---|
| 两市成交额重复计算 | 创业板/科创板成交额已含在深市/沪市，**不能四指数相加** |
| 金额单位 | akshare 部分接口返回万元或亿元，取回后立刻归一到元 |
| 复权口径 | 本项目固定 `qfq`（前复权），与看盘软件一致 |
| 行业分类标准 | 东财、申万、证监会分类不同，同一只票可能归到不同板块 |
| 涨停家数口径 | 乐咕乐股与东财涨停池的口径不完全一致（是否含 ST、是否含新股） |
