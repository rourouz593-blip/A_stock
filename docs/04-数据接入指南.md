# 04 · 数据接入指南

> ⚠️ 2026-09-04 更新：上证、深证、创业板日线使用 Baostock；Baostock 不返回的
> `sh.000688`（科创50）日线与四大指数分钟线使用 AShare 兼容的新浪/腾讯端点。
> 持仓快照与前复权日线也使用腾讯；新浪个股日线没有 `qfq`，因此不作为备源。
> 另：**数据流量一律直连，只有 LLM API 走代理**——挂 VPN 抓境内行情只会让封禁来得更快。

数据层已经全部实现。本篇讲**它是怎么组织的**，以及你要加一类新数据时怎么做。

## 一、数据源边界

决策记录见 `memory/decisions/0002-akshare.md`。三句话：

1. **零凭据门槛** —— 免费、不需要 token，`pip install` 后即可运行。
2. **覆盖最全** —— 涨停池、炸板池、连板数、板块资金流这些**短线复盘必需**的数据，
   Tushare 要高积分，BaoStock 根本没有。
3. **指数行情独立** —— 三只指数日线走 Baostock，科创50 日线与指数分钟线走
   新浪/腾讯；来源按数据能力划分，不再经过东方财富。

代价是：背后是第三方网页接口，会限流、会抽风、字段偶尔变。
所以有了 `agents/data_engineer/scripts/ak_client.py`。

## 二、三层结构

```
tools/fetch_dataset.py                         ← 稳定兼容入口
  └─ agents/data_engineer/tools/fetch_dataset.py
       └─ agents/data_engineer/scripts/build_dataset.py
            ├─ scripts/fetch/*.py              ← 每类数据一个 DataBlock
            └─ scripts/ak_client.py            ← 统一重试、缓存、响亮失败
```

**为什么要包 `ak_client` 这一层？**

1. 重试逻辑只写一次，不用在六个 fetch 模块里各抄一遍
2. 本地缓存让调试快十倍，也少给数据源添麻烦
3. **失败必须响亮**：`call()` 拿不到数据就抛 `FetchError`，
   绝不返回空 DataFrame 让上层误以为"今天就是没数据"

必需数据用 `call()`（失败即抛），可选数据用 `try_call()`（失败返回 None + 错误信息）。
`northbound` 用的就是 `try_call`——缺了不该阻塞整个复盘。

## 三、DataBlock：每一块数据的统一形状

```python
@dataclass
class DataBlock:
    status: "ok" | "degraded" | "missing"
    provenance: Provenance      # 源、取数时间、参数、单位 —— 缺了报告就不可追溯
    rows: int | None
    path: str | None            # 明细 CSV 路径
    inline: Any                 # 小体量摘要，直接进 dataset.json
    flags: list[QualityFlag]    # 发现的问题，只标记不修改
```

**`inline` 与 `path` 的分工很关键**：
涨停池有一百多行、板块有四百多个，全塞进 `dataset.json` 会撑爆模型上下文。
所以 `inline` 只放摘要（前 25 名、统计量），明细落 `data/<run_id>/*.csv`，
agent 需要回查时自己去读 CSV。

存 CSV 而不是 parquet，是为了让你能直接用 Excel 打开核对（`utf-8-sig` 编码不乱码）。

## 四、A 股特有的六个坑（代码里都处理了）

| 坑 | 症状 | 处理在哪 |
|---|---|---|
| **两市成交额重复计算** | 成交额虚高约 30% | `clean/derive.py:two_market_amount` 只取上证+深成 |
| 分时数据只留几天 | 历史日期拿不到日内四段 | `fetch/market.py` 标 degraded + flag |
| 炸板/跌停池只留 30 天 | 取历史直接报错 | `try_call` 捕获后标 warning |
| 涨跌家数是实时快照 | 盘中调用拿到中途数据 | 只在收盘后跑 `close` 模式 |
| 停牌不产生行情 | 均线在停牌区间莫名平滑 | 按交易日历跳过，不补值 |
| 复权口径 | 均线与看盘软件对不上 | 固定 `qfq`，写进 `dataset.adjust_mode` |

第一条最值得展开。很多人会这样算两市成交额：

```python
total = sum(i["amount"] for i in index_snapshot)   # ❌ 错
```

创业板指的成交额**已经包含在深证成指所在市场里**，科创50 同理包含在沪市里。
这样加会多算三成。正确做法只取上证 + 深证成指——
`tests/test_derive.py::test_two_market_amount_does_not_double_count` 守着这条。

## 五、加一类新数据：四步

以"两融余额"为例：

```python
# ① agents/data_engineer/scripts/fetch/margin.py
def fetch_margin(as_of: str) -> DataBlock:
    df, err = try_call("stock_margin_sse", {"start_date": ..., "end_date": ...})
    if df is None:
        return DataBlock(status="missing", provenance=Provenance(...),
                         flags=[QualityFlag("margin", "warning", f"两融取不到: {err}")])
    return DataBlock(
        status="ok", rows=len(df),
        inline={"balance_yi": ..., "chg_yi": ...},
        provenance=Provenance(source="akshare.stock_margin_sse",
                              fetched_at=now_iso(), unit="CNY_yuan"),
    )
```

## 六、怎么写测试（不联网）

看 `tests/test_breadth.py`：用 `monkeypatch` 把 `try_call` 换成返回假 DataFrame 的函数。

```python
def fake_try_call(name, params=None, cache=True):
    return (mock_data[name].copy(), None) if name in mock_data else (None, "not mocked")

monkeypatch.setattr(breadth, "try_call", fake_try_call)
```

**至少要测两种情况**：

1. 正常数据 → 计算结果对不对
2. **数据取不到 → 是不是诚实地返回 None + flag，而不是编了一个数**

第 2 类测试比第 1 类更重要。第 1 类错了你会发现，第 2 类错了你不会发现——
系统会安静地给你一份编造的报告。

## 七、踩到新坑怎么办

写进 `memory/knowledge/akshare-gotchas.md`，格式：

```
### <接口名> — <一句话概括>
- 现象：
- 影响：哪个 agent 的哪类结论会被污染
- 处理：
- 发现于：YYYY-MM-DD，run_id
```

**"影响"那一栏是关键。** 记录一个坑而不写清它污染什么，
下次别人看到只会觉得"哦"，不会知道该去检查哪份产物。
