# 新闻分诊

## 0. 立场

一天几百条快讯里，真正能影响明天定价的通常不超过五条。
**这个技能 80% 的内容是教你怎么扔掉那 95%。**

## 1. 信源分层

| 层级 | 信源 | 可信度 | 权重 |
|---|---|---|---|
| T1 | 交易所公告、监管文件 | 事实 | TODO |
| T2 | 财联社电报、新华社 | 较可信 | TODO |
| T3 | 门户财经快讯、券商研报 | 有立场 | TODO |
| T4 | 社交平台、股吧、小作文 | 噪音为主 | TODO |

<!-- TODO(strategy): 权重数值待定。原则：T1 与 T4 的权重差至少一个数量级 -->

**T4 的信息不是不能用，是不能作为唯一依据。**
"某某小作文说要出政策"可以记录为 `certainty: rumor`，但不能据此判断利好。

## 2. 去重

1. 标题前 24 字相同 → 同一事件（取数层已做）
2. 语义相同但措辞不同 → 人工判断合并（这一步需要模型）
3. 合并时**保留层级最高的那条**作为主条目，其他作为佐证

## 3. 过滤例行公告

下列不算事件，直接扔：
日常关联交易、股东大会通知、董事变更（非核心）、募集资金存放、
例行信息披露、常规回购进展。

## 4. 三分类的判定

利好 / 中性 / 利空，判断标准是**对次日定价预期的影响方向**，不是对公司好不好。

- 业绩超预期但股价已涨三倍 → 未必是利好
- 监管问询函 → 通常利空，但如果市场早有预期，可能是利空出尽
- 政策文件 → 看是"定调"还是"落地"，落地往往是利好出尽

**注意**：不要做"利好出尽是利空"这类无法证伪的解读。
如果要这么判，必须给出可验证的依据（比如该板块已连续三日放量上涨）。

## 5. 确定性标注

| certainty | 含义 | 规则 |
|---|---|---|
| `fact` | 已发生的事实（公告、数据） | 必须有 T1/T2 来源 |
| `reported` | 媒体报道，未经官方确认 | 标明报道方 |
| `rumor` | 传闻、小作文 | **永远不能升级为 fact**，哪怕后来兑现 |

为什么传闻兑现了也不能改标？因为那会让你误以为"跟传闻是对的"，
而你看到的只是**幸存者偏差**——没兑现的传闻你不会回头去看。

## 6. 次日验证（本技能最重要的一节）

每天读 `memory/runs/` 里昨天的 `news.json`，把昨天标为利好/利空的条目，
用今天的价格反馈对一遍：

| verdict | 判定 |
|---|---|
| 兑现 | 相关板块/个股按预期方向走了 |
| 部分兑现 | 方向对但幅度远小于预期 |
| 证伪 | 走了反方向 |
| 待观察 | 影响尺度是数日或中期 |

**不做这一步，这一章永远是事后诸葛亮。**
连续验证两周之后，你会发现自己有系统性的解读偏差——那才是真正的收获。

## 7. 硬约束

- **不能仅凭新闻推荐个股。** 新闻给方向，标的由次日价格反馈确认。
- 无来源、无时间戳的信息一律丢弃。
- 当天确实没有重要新闻 → 写"无重大事件"，这本身是有用信息。
